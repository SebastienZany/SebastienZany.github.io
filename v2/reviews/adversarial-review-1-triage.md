# Adversarial review #1 (Codex, 2026-08-14) — triage and dispositions

> Source: `codex exec` adversarial review of the v2 planning docs at staged-tree state, gpt-5.6-sol
> @ ultra, read-only sandbox. 35 findings, severity-ranked. This file records the verdict on each
> and the amendment it drove. Amendments are applied to PLAN.md and briefs M0–M3 in the same
> commit that adds this file. The review's own mesh-audit numbers (fold histogram, corner census,
> 768-packing arithmetic, same-chart pair count) are recorded as **expected values for M1/M2 to
> confirm or refute** — they were produced by a fallible reviewer and are load-bearing, so the
> tools measure them rather than trusting them.

Legend: ✅ accepted (plan changed) · ◐ partially accepted (plan changed with narrower scope +
rationale) · ❌ rejected (with reason).

| 1 | high | In-place gutter fill (sample + storage-write same texture) is illegal | ◐ | The naive form is illegal, but core WebGPU allows **`read_write` storage access on `r32float`** — exactly our sim-field format. Fill becomes a single read_write-storage pass with two added obligations, now in PLAN §1.2: donors must be **authoritative-only** (bake-verified; no gutter-reads-gutter), and the display copy (a different resource) is filled by reading the sim field, so no same-resource hazard exists there. | 2 | high | `pinv(J_dst)·J_src` collapses transverse displacement at folded seams (3,718 pairs >60°) | ✅ | Mathematically right and the sharpest finding in the review. The extrinsic projection is only exact for coplanar pairs; the correct cross-seam map for an *intrinsic surface field* is the **hinge-unfold affine**: rotate the source tangent plane onto the destination plane about the shared 3D edge, then map — `M = pinv(J_dst)·R_hinge·J_src`. Legacy's shipped ptex used the projection form, and its synthetic validation (`f(worldPos)`) was structurally blind to this: an extrinsic test function makes the extrinsic map look right. PLAN §1 and M2 now specify hinge-unfold, and the M2 affine-fidelity test now samples **transverse rows at ±1..GUTTER texels** against a geodesic/unfold reference, not just the shared edge (edge-only sampling cannot see the collapse). Fold histogram measured + reported at bake. |

## Reference-doc corrections driven by the review

- `webgpu-prototype-assessment.md`: the claim that the prototype's child admission/debit "matches
  main.js's deferred-debit allocator" is **wrong at capacity** (finding 13) — legacy guarantees
  parents always win; the prototype can drop a surviving parent. Correction note added in place.
- Same doc: "sim.js matches main.js semantics" is too strong — economy lacks exposure-based
  field depletion (finding 14), density persistence is invented (29), reproCrowdCap is invented
  (17), oats are summed into the canonical field (16). The verdict (adopt the *skeleton*)
  stands; the semantic gap list is now explicit.
- `legacy-gpu-inventory.md`: population-controller anchor corrected (main.js:19166 stores a base
  threshold; the live controller is the supply-rate actuator near main.js:19359).

## What was NOT conceded

- #1's "requires ping-pong / full-field rewrite" — refuted by r32float `read_write` storage
  (with the donor-authoritative obligation making it race-free).
- #6/#11/#28 as *regressions* — they are inherited legacy limitations, now documented and
  measured instead of silently carried.
- #9's severity — separable Gaussian removes the rotation half of the objection; what remains is
  the same anisotropy class legacy always had.
